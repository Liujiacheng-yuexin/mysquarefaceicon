已具备

  • app/sitemap.ts 已将首页、信任页、主要支持页、博客和法律页写入 sitemap。
  • app/robots.ts 允许公开页面抓取，禁止 /admin/ 和 /api/。
  • 英文首页是唯一已审校语言首页，其他语言页已保留测试入口但 noindex。
  • 核心工具页保持首屏可见，使用本地 Ruffle 与授权 SWF，并保留 Canvas/故障路径。
  • 社区评论、Gallery 与 like API 已接入，仍需生产 KV/R2 实测。

高优先级风险

  • www 和 workers.dev 入口如果仍返回 200，会造成重复入口，应统一跳转或关闭。
  • npm run cf:build 在 Windows/OpenNext 环境曾因权限问题失败，生产构建应在 WSL 或 Linux CI 验证。
  • Cloudflare Worker 日志里的 errors 需要按状态码和路径拆分，不能只看 Requests 总量。
  • noindex 支持页和多语言页不要重新进 sitemap，除非完成内容质量升级或母语审校。
  • 上线后需要提交 sitemap、请求首页索引，并用 GSC 区分“搜索点击”和 Cloudflare 请求。

优先行动

建议按影响范围排序处理。

  1. 确认 https://mysquarefaceicon.com 为唯一主站，www 做 301/308，关闭或重定向 workers.dev。
  2. 在 Cloudflare 生产环境验证 KV/R2、评论审核、图片代理、like API 和 Worker 错误日志。
  3. 跑通 Linux/WSL 的 npm run cf:build，再部署 Worker。
  4. 提交 /sitemap.xml 到 GSC 和 Bing，使用 URL Inspection 请求首页索引。
  5. 等 GSC 有 impressions 后，只扩展有明确搜索意图且能链接回工具的页面。
维护建议：每次新增生产页或修改索引策略后，更新本页的页面数组、PAGE_PLAN.md、SEO_LOG.md 和 sitemap；只做内部监测页本身不需要进入 sitemap。
