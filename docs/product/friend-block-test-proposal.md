## 2. 布局与交互

沿用奶油底、薄荷绿与橙色操作按钮、8px 圆角的详情模板：**页头 → 面包屑 → H1 和一句用途说明 → 游戏面板 → 播放器控件/事实 → 相关游戏 → 三步玩法 → 独立实现说明 → 功能与提示 → FAQ → 来源 → 更多游戏/首页 → 页脚**。游戏入口在首屏，正文不挤占首屏；保留现有点击启动方式。

游戏面板使用同一套三阶段界面，手机单列、每屏一道题、四个大选项、明确进度和上一题/下一题；桌面居中，避免控件过宽。复用项目头像样例，并逐项登记素材路径及出处。

1. **出题**：选头像、昵称（最多 16 个字符），从不少于 20 道原创友好题中回答 10 道；每题 4 个选项，可换成未使用的题。完成后复制测验链接。
2. **答题**：打开链接显示出题人，朋友选头像和昵称，猜完 10 题后显示分数及档位。拟定四档：0–3 题 `Getting in Sync`、4–6 题 `Good Vibes`、7–8 题 `Close Crew`、9–10 题 `Same Wavelength`。提供复制成绩链接、自己出题、去首页做头像。
3. **收成绩**：出题人打开回传链接查看成绩，存入本机列表；重复链接去重，支持清除本游戏记录。存储被禁用或满额时仍可完成游戏，并明确提示未保存。

触控目标至少 44px；320px 无横向滚动；键盘可完成全流程，焦点可见、状态有文字提示。FAQ 覆盖独立站点/链接不通用、保存位置、无需注册、手机支持和链接损坏恢复；说明这是轻松娱乐，不用于判断真实友谊。

## 3. 分享、隐私与接入

静态 HTML/CSS/JS 放在 `public/games/friend-block-test/`，复用 HTML5 adapter；新增一条游戏记录、分类、原创实现许可记录和图片清单，旧 Registry 的 UNKNOWN 保持。封面、缩略图、OG 由本项目代码绘制或经核对的项目素材组合。

测验与成绩数据只在游戏页的 `#` 片段内，版本号、严格结构校验、校验码和 1,800 字符上限覆盖两种链接；地址不使用查询参数。损坏、截断和未知版本显示可恢复提示。昵称去控制字符、链接和标签，仅按纯文本渲染。校验码用于发现损坏，不宣称防作弊或保密；得到链接的人能读取其中内容。

**已核实的接入缺口**：HTML5 adapter 目前只加载 `entryUrl`，不会传入父页面片段；播放器默认 16:9 不适合手机问答。实现时限定本记录补齐片段传递、返回链接和合适的面板高度，回归其它播放器。

**需随本方案确认的隐私调整**：附件要求沿用详情页广告政策，但现有根布局会加载 GA，延迟脚本还会加载广告/统计；这些脚本与包含昵称及答案的分享地址处于同一页面。建议仅对本测验页和静态入口复用 Discord 图片工具的第三方脚本隔离及完整文档导航边界，包括平台可能注入的统计，保证测验数据不进入统计、广告或错误上报。现有页面策略保持。游戏只读取本地静态资源，不调用 API、不上传内容、不接后端或新增 Cloudflare binding。隐私政策/条款增加对应本地记录、分享链接和清除说明。
