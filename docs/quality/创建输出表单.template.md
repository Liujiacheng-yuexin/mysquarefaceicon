# 创建输出表单

本文件用于规范每次创建新网站、规划新页面、审查页面或安排内容优化任务时的输出表单格式。

目标：让每个网站的开发任务、页面 URL、所属网站、当前状态和截止日期可以被持续追踪，避免任务分散在聊天记录中丢失。

## 使用场景

以下情况必须更新输出表单：

- 新增一个网站项目。
- 为某个网站规划首批页面。
- 新增页面开发任务。
- 新增页面审查或优化任务。
- 新增 blog / guide / FAQ / landing page 任务。
- 调整任务状态、截止日期或预估工作量。

## 必填字段

输出表单至少包含以下字段：

| 字段 | 说明 | 示例 |
|---|---|---|
| 任务描述 | 任务要做什么，必须具体到页面或动作 | 审查并优化 Cursive Copy and Paste 指南，补充 Unicode 原理、平台兼容、复制后显示变化、何时使用 PNG/SVG |
| URL | 页面路径，使用站内相对路径 | /guides/cursive-copy-and-paste/ |
| 网站 | 网站名称或项目代号 | makecursive |
| 状态 | 当前状态 | 待开始 / 进行中 / 已完成 / 暂停 |
| 任务截止日期 | 计划完成日期，格式 YYYY/MM/DD | 2026/05/18 |
| 预估工作量 | 可选字段，用数字表示预估工作量、复杂度或版本批次 | 2.0 |

如果用户只要求 5 个字段，则输出：任务描述、URL、网站、状态、任务截止日期。
如果用户提供了第 6 列数字，例如 2.0、2.5，则保留为“预估工作量”。

## 状态规则

状态建议只使用以下值：

- 待开始
- 进行中
- 已完成
- 暂停
- 取消

如果用户没有指定状态，新任务默认使用：`待开始`。
如果任务已经开始执行，使用：`进行中`。
如果本轮已经完成并验证，使用：`已完成`。

## 日期规则

- 日期格式统一使用 `YYYY/MM/DD`。
- 如果用户没有指定截止日期，先留空或标记为 `待定`。
- 不要擅自编造截止日期。
- 如果用户给出相对日期，例如明天、下周五，应转换成明确日期。

## 更新规则

每次新增网站或页面任务时，必须：

1. 读取现有输出表单。
2. 保留已有行，不要覆盖历史任务。
3. 追加新任务行。
4. 如果任务已存在，则更新状态、截止日期或描述，不要重复创建相同 URL 的任务。
5. 输出本次新增或更新了哪些行。

## 给 Codex 的提示词

```text
请根据当前网站规划、关键词 Excel、问题 Excel 和页面开发计划，更新“创建输出表单”。

每条任务必须使用以下字段：

- 任务描述
- URL
- 网站
- 状态
- 任务截止日期
- 预估工作量

要求：

1. 任务描述必须具体，不能只写“优化页面”。
2. URL 使用站内相对路径。
3. 网站填写项目代号或网站名称。
4. 状态默认使用“待开始”，已开始的任务使用“进行中”。
5. 任务截止日期使用 YYYY/MM/DD；没有明确日期则写“待定”。
6. 如果用户提供预估工作量，则保留；没有提供可以留空。
7. 不要重复添加相同 URL 的任务。
8. 如果已有任务状态变化，请更新原任务行。
9. 输出 Markdown 表格；如果用户要求方便粘贴到表格工具，则额外输出 TSV 格式。
```
