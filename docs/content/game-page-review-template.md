# 单页游戏内容审核记录模板

配套标准：[游戏页面独特内容与事实 QA 标准](game-page-quality-standard.md)。

这是可复制的证据记录，不是任务看板。复制到当前已授权任务的证据目录；只记录该页，不生成新任务。模板中的空值、未验证和未完成人类审核必须由真实证据替换，不得整表预填“通过”。以下字段不属于 GameRecord，也不应直接写入运行数据。

## H. 复核触发与历史保护

游戏文件/版本、交付类型、URL、相关文案、平台行为、一手来源或条款有变化时，重新核验受影响 claim；记录新日期并保留旧记录。字段绑定没变不代表外站或设备行为没变。不要用新的规范、通过截图或用户验收覆盖旧失败、UNKNOWN、未完成的完整 Oval 模板迁移或已取消 LICENSE-GATE 的事实。
